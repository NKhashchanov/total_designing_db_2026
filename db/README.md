# FoodExpress

FoodExpress — база данных сервиса доставки еды. Хранит клиентов и адреса, рестораны и меню, заказы, платежи, отзывы и историю выплат курьерам.

СУБД — PostgreSQL 17. Рабочая схема — `mineev_food`. Для генерации UUID используется расширение `uuid-ossp` в схеме `exts`.

## Быстрый старт

Требуется PostgreSQL 17, расширение `uuid-ossp` и клиентские утилиты PostgreSQL.

В пустой базе `foodexpress` установить объекты из корня репозитория:

```bash
psql -h 127.0.0.1 -U postgres -d foodexpress -X -v ON_ERROR_STOP=1 -f db/install.sql
```

Для восстановления готовой схемы используется `db/foodexpress_mineev.backup`. Подготовка базы, установка расширения, восстановление и настройка прав описаны в [руководстве по развертыванию](docs/getting-started.md).
